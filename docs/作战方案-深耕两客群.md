# 两客群共用机制

1. **跑动资源再配置**：重复跑（366家/2359次）减半 → redirect 到漏跑（77家）+ 沉睡层。一次调配补上大部分漏跑缺口，不加人。
2. **漏跑督办制**：每月系统自动出漏跑名单（R>30且M≥1万且期0拜访）→ 按分销商点名 → 次月核验补访率。
3. **升级追踪**：浅购→活跃→核心的层间迁移数 = 深耕战北极星指标（呼应71家的状态迁移管理）。
4. **真实性哨兵**：层间跃升异常（浅购单月爆量升核心）自动标记 → 访谈核实（萧山规则）。
