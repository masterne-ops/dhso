# 代理商盘库明细 (inventory_snapshot)

> M5 进销存模块核心数据 — 序列号级库存快照,每季度更新。
> 入库脚本:`migrations/load_inventory.py`

## 数据源
- 文件:`盘库明细报表分析_YYYYMM.xlsx`(单 sheet,~60 万行 × 42 列,全浙江)
- 生产存:`/opt/so-data-analytics/data/quotations/` 或 `/tmp/`(大文件不进 git)
- 更新频率:**每季度**(SMB 代理商盘库活动)

## 表 inventory_snapshot
- 主键:`(产品序列号, 盘库季度)`
- 行数:547,574(去重后)

## 口径(已确认)
| 口径 | 规则 |
|---|---|
| 去重 | 按 (序列号, 盘库季度) 去重,同组取盘库时间最新一条 |
| 全入 | 25年 / 2026Q1 / 2026Q2 各季度都入(时序看趋势)|
| **严口径** | `是否在库 = 1`(上线时间为空 = 真在库);分析默认用此 |
| 库龄 | `库龄天数` = 盘库时间 − 出库时间 |

## 派生字段
- `盘库季度`:从盘库活动名称提取(2026Q2 / 2026Q1 / 2025 / 其他)
- `是否在库`:上线时间为空 → 1,否则 0(盘后已动销)
- `库龄天数`:盘库时间 − 出库时间(呆滞判断)

## 每季度更新 SOP
1. 拿到新盘库 Excel → 改名去空格 → scp 到生产 /tmp/盘库明细.xlsx
2. 改 `load_inventory.py` 的 `extract_quarter`(加新季度识别,如 2026Q3)
3. 跑脚本(全表 DELETE + 重灌,因为去重后是完整快照)
4. 校验季度分布 + 货值

## 可支撑的 M5 分析
- 库存货值(全品类 / 分专项 / 分代理商)
- 库龄分布 + 呆滞品(>365天)
- 库存周转(SO ÷ 平均库存)
- 季度趋势(Q1→Q2 库存变化)
