### 2.3 进度条算法(已落地)

- 地市级 SO 进度条 = 城市 SO YTD ÷ (城市 kpi_targets × Σ kpi_rhythm.省区SO进度条[1..上月])
- 代理商级 SI 进度条 = 代理商 SI YTD ÷ (代理商目标 × Σ kpi_rhythm.客户SI进度条[1..上月])
  - 续签客户用续签节奏
  - 新签客户:用「续签节奏[m] ÷ Σ续签[签约月+1..12]」runtime 计算

### 12.2 销售链条三环节调研(实事求是)

#### 环节 ① 终端业主(End User)
> 实际买摄像机装在自家工厂/店铺/家里的人

**核心问题**:
- 选海康/大华时怎么决策?(性能 / 品牌 / 价格 / 售后 / 渠道推荐)
- 用过夜视王2.0 的反馈?
- 价格敏感度阈值是多少?
- 主要购买渠道(线上/线下/熟人推荐)?
- 对"夜视王"和"臻全彩"两个 IP 的认知度?

**调研方式**:
- 通过服务商收集装机后客户反馈(问卷 / 电话回访)
- 老用户回访(已装大华产品的)
- 流失客户分析(本来用大华,后来转海康)

#### 环节 ② 销售渠道(Channel,即服务商/经销商/工程商)
> 把产品卖给终端的店铺/工程商,夹在代理商和业主之间

**核心问题**:
- 库存里 臻全彩 vs 夜视王2.0 各多少?(库存意愿)
- 主动推哪个利润高?
- 客户主动问哪个多?(品牌认知 / 营销影响)
- 哪个售后问题多?(品控)
- 大华政策(返利/支持) vs 海康政策的对比感受
- 安装培训 / 技术支持的方便度

**调研方式**:
- 业务员跑动时问(visit_record 系统化收集)
- page 06 业务员跑动评估 增加"问询字段"
- 老服务商座谈(在推广会上设置专项议题)
- DB 数据分析(哪些服务商在卖 / 哪些没卖,客户结构对比)

#### 环节 ③ 代理商(Tier 1 Distributor)
> 拿货的一级分销商,资金大、覆盖广

**核心问题**:
- 进货价 / 出货价对比(臻全彩 vs 夜视王2.0)
- 海康给代理商什么政策(返利 / 区域保护 / 营销支持)?
- 大华现行政策与之差距?
- 销售人员激励差异?
- 仓库压货风险评估?
- 重点客户拉单时,会主动推臻全彩还是夜视王2.0?

**调研方式**:
- 月度对标会上专项问询(在 page 20 业务对标 tab 加调研问卷模块?)
- 一对一座谈(50 家代理商挑 10 家深度沟通)
- 业务员反馈(代理商口风的二手情报)

### 13.4 攻坚优先级算法

```
+ 同类产品当期货值 × w1
+ 服务商等级 V4/V3/V2/V1 × w2
+ 阵地标签 摇摆+5 / 我方+2 / 敌方+1 × w3
- 流失风险 × w4
```

→ 自动算分,Top N = 当月业务员攻坚名单。

#### 13.9.2 销售链条三环节调研(实事求是)

##### ① 终端业主(End User)
> 实际买摄像机装在自家工厂/店铺的人

**核心问题**:
- 选海康/大华时怎么决策?(性能 / 品牌 / 价格 / 售后 / 渠道推荐)
- 用过夜视王 2.0 的反馈?
- 价格敏感度阈值?
- 主要购买渠道(线上/线下/熟人)?
- 对"夜视王" vs "臻全彩" 品牌认知度?

**调研方式**:服务商代收问卷 / 老用户电话回访 / 流失客户分析

##### ② 销售渠道(服务商 / 经销商 / 工程商)
> 把产品卖给终端的店铺

**核心问题**:
- 库存意愿(各放多少)
- 主动推哪个利润高
- 客户主动问哪个多
- 售后问题对比
- 大华政策 vs 海康政策的感受
- 安装培训 / 技术支持方便度

**调研方式**:跑动时问询 + page 06 增加问询字段 + 推广会专项议题

##### ③ 代理商(Tier 1 Distributor)
> 一级分销商,资金大、覆盖广

**核心问题**:
- 进货价 / 出货价对比
- 海康政策(返利 / 区域保护 / 营销支持)
- 大华现行政策差距
- 销售人员激励差异
- 仓库压货风险
- 拉单时主动推哪个

**调研方式**:对标会问询 / 1-on-1 座谈(50 家代理商挑 10 家深度沟通)
