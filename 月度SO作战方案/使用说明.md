# 地市月度SO作战方案 · 使用说明

> 给地市负责人做 6 月 SO 任务派发 & 资源投放的工具。数据截止 **2026-05-29**(生产库最新)。

## 文件

| 文件/目录 | 作用 |
|---|---|
| `分发/{城市}_SO作战方案.html` | **发给各地市负责人的单文件**(11 个),数据已内联,**任意浏览器双击即用**,只含本市数据 |
| `分发/浙江省_SO作战方案_全省版.html` | 省级单文件,含全部 11 市 + 全省汇总,可下拉切换 |
| `地市月度SO作战方案.html` | 开发母版(读外部 json,用于联调/截图) |
| `so_plan_data.json` | 预计算数据(母版用) |
| `build_so_plan_data.py` | 重新生成 JSON 的脚本(每月更新数据后跑,只读) |
| `build_dist.py` | 把 JSON 内联进 HTML、生成分发版的脚本(本地跑,无需DB) |

## 怎么用

- **分发给各地市**:把 `分发/杭州市_SO作战方案.html` 发给杭州负责人,双击即开(Chrome/Edge/Safari/Firefox 都行,无需服务器、无需联网)。每个文件只有本市数据,锁定本市。
- **省级总览**:用 `分发/浙江省_SO作战方案_全省版.html`,顶部下拉切城市或看全省汇总。

## 5 个板块

1. **城市概览**(只读):6月目标=年度目标×9.5%(节奏);截止当前完成、进度条达成率、25年1-6月、25年6月单月、同比。
2. **区县SO分配**:默认按区县年度目标×节奏,可改;底部校验 Σ区县=城市6月目标;每区县填责任分销经理;可导出。
3. **代理商SO分配**:6月目标=签约值×0.7×9.5%(可改);填「已明确预测」,「未明确缺口」自动算;填责任经理;可导出。
4. **服务商 价值×成长矩阵(波士顿)**:26年1-5月安装红包,**价值=上线金额**(产品现有分销价),**头部(按金额从高到低累计占全市约80%金额)为高价值**;**成长=近2月(4-5月)月均 vs 前3月(1-3月)月均**。四象限:
   - **明星**=高金额·**上升** → 重点加码  ·  **金牛**=高金额·**平/降** → 守住稳产
   - **问号**=低金额·上升 → 潜力培育  ·  **瘦狗**=低金额·平/降 → 观察
   - **展示全部服务商**,默认筛选金牛+明星,可切象限/搜索/排序。每行带 **6月基线**(过去6月月均,必做底线)与 **增量(=目标产出−基线)**。填责任经理/动作/投入预算/6月目标产出;可导出。
5. **预算投放汇总**:把④"有投放/有目标"的服务商按代理商归集(投入/基线/目标/增量),叠加代理商级投放(对赌/会销/满赠/活动/其他,人工填),同时出 **总量ROI**(目标÷投入)与 **增量ROI**(增量÷投入,真回报);可导出。

> **增量逻辑(v1.2)**:基线=过去6个月月均上线金额,是不投也有的量、必须做到的底线;投放只为增量(目标−基线)负责。看增量ROI 决策,避免给"投不投都那样"的客户砸钱。

6. **代理商SO计划(任务制定)(v1.3)**:选单个代理商下钻——5 张卡(SO目标/基线保底/增量需求/已规划/缺口)+ ①名下服务商目标分解(与④同源,改一处两处都变)+ ②自由任务行(拓新/铺货/回款/活动,可增删,目标产出计入覆盖)+ 底部缺口校验。给分销经理逐个代理商做计划用;可导出本代理商计划 CSV。

## 暂存与导出

- 所有手填内容**自动保存**在浏览器本地(localStorage),关掉再开还在;换电脑/浏览器不通用。
- 每板块右上「⬇ 导出」生成 CSV(Excel 可直接打开)。
- 「重置本市」清空手填;「打印/PDF」出纸质版。

## 收集汇总流程(A 方案 · 无后端)

1. **各地市负责人**填完 → 点顶部「⬇ 导出我的填写」→ 得到 `{城市}_填写.json` → 发回汇总人。
2. **汇总人**打开全省版 → 点「📥 导入各市填写」→ 一次多选所有收到的 json → 自动合并到对应城市。
3. 点「📤 导出全省汇总」→ 一次得到 4 张 CSV(区县 / 代理商 / 金牛明星投放 / 预算投放),含全部地市。

> 导出我的填写键只在**分城市版**显示;导入 / 全省汇总键只在**全省版**显示。
> 金牛明星投放汇总只导出"已填投放(动作/预算/产出任一非空)"的服务商,聚焦实际投放计划。

## 下月更新数据

1. 数据入库后,改 `build_so_plan_data.py` 顶部 4 个常量(YEAR / REF_DATE / DATA_CUTOFF / CUR_MONTH)。
2. 生产库重生成 JSON:
   `ssh root@121.196.152.24 'python3 -' < build_so_plan_data.py`
   `ssh root@121.196.152.24 'cat /tmp/so_plan_data.json' > so_plan_data.json`
3. 重新生成分发版:`python3 build_dist.py`(产物在 `分发/`)。

## 口径(与系统 panorama 一致)

- **SO** = `product_flow.最新分销价 / 万`,按**上线城市/区县**归口,日期取**上线时间**。
- **6月节奏 9.5%**、**YTD(1-5月)节奏 34%** 来自 `kpi_rhythm「省区SO进度条」`。
- **代理商签约值** 来自 `dealer_si_snapshot.签约金额`,责任经理=`客户所有者`。
- **服务商价值** = 安装红包当年1-5月**上线金额**(`产品现有分销价`,覆盖99.9%);1-5月无活跃不进表。
- **成长趋势** = 近2月月均 ÷ 前3月月均 − 1(前期无量记「新增」)。
- **服务商基线** = 该服务商**过去6个月(2025-12~2026-05)月均上线金额**(同口径,÷6)。
- **增量** = 6月目标产出 − 基线;**增量ROI** = 增量 ÷ 投入(真回报),**总量ROI** = 目标 ÷ 投入。
