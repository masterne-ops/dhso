# 代理商目标分解 + 下月激励方案 · 通用方法论 v1

> 目的：输入**任意一家一级代理商**，自动产出「目标全景（现状→年底→次年翻倍）+ 下月目标 + 全维度激励方案」。
> 本文件是方法论沉淀，后续可做成 **skill（输入代理商名→出方案）** 或 **网页功能**。
> 首个落地案例：杭州万仞科技（见 `万仞6月目标与激励方案-2026-06.html`）。

---

## 一、核心理论模型

```
SI ∝ SO                              （卖多少进多少，SI不单独激励，跟随SO）
SO = Σ档位[ 客户数(档) × 客均产出(档) ]   （服务商规模结构分布 × 客均年产出）
```

- **不激励**已是强项的因子（如客均产出已全省第一的代理商）。
- **激励**有缺口的因子：客户数（激活/留存/新签）、结构（升档）、品类。
- **资源分配铁律**：缺口最大 × 杠杆最陡 → 投入最多。

## 二、6步生成流程

### 第1步 · 定全年锚
- **SO全年目标**：取 `so_plan`（地市目标 × 代理商拆分系数）或 6月目标÷6月节奏占比反推；与 `dealer_si_snapshot.签约金额` 互校。
- **SI全年**：签约金额；月度按 ∝SO 比例跟随。
- **次年目标**：当年 ×2（量类指标全部翻倍；品类除外，见第4步）。

### 第2步 · 进度条拆月
- 逐月目标 = 全年目标 × `kpi_rhythm` 月度节奏占比（**不可用÷12**，安防有明显季节性）。
- 台数 = 金额 ÷ 均价（默认180元/台，可按代理商实际客单价调）。
- 标注 YTD 已完成 vs 节奏应达成，判断是否"累计超额但月度下滑"（警惕假象）。

### 第3步 · 服务商引擎诊断（SO = 客户数 × 客均产出）
1. **剔马甲**：`vest_account` 按 `对应一级` 匹配，马甲出货归"项目(无服务商)直单"，不算真实渠道。
2. **分档客均阶梯**（成交额口径，剔马甲）：
   - V2 ≥0.1万 / V3 ≥1万 / V4 ≥3万，算各档 客户数 / 客均 / 累计贡献占比 → 看二八集中度与升档杠杆。
3. **三大缺口**：
   - 激活率（活跃户/签约户）vs 全省；签约未成交的"V0池"有多大。
   - **月月动销**（连续动销服务商数）——衡量复购盘/稳定度，多数代理商这里是最大短板。
   - 升档空间（各档现状 vs 目标）。

### 第4步 · 品类结构诊断（三大专项）
- 算 无线 / 夜视王 / 场景化 的占比（**台数 & 金额双口径**），对标：
  - **全省均值**（合理性基准）、**标杆天花板**（≥2000台代理商的最高占比）、**该代理商排名**。
- 定占比目标：低于全省均值的→补到均值（次年冲标杆）；已超的→维持/扩大；高客单价品类用**金额占比**衡量。
- 次年统一收敛到均衡结构（如 10/10/10）。

### 第5步 · 6维目标生成
| 维度 | 指标 | 目标定法 |
|---|---|---|
| 总量 | SO / SI | 第1-2步进度条 |
| 客户数·激活 | 当月激活服务商 | 维持/提升近月跑速 |
| 客户数·留存 | 月月动销服务商 | 对标全省中位3%/标杆8%，或挂base-load(每家≈2万/月) |
| 结构·升档 | V2/V3/V4 家数 | 现状→年底目标，分解月均 |
| 质量·底盘 | base-load自有出货 | 月度爬坡到目标值 |
| 品类 | 无线/夜视王/场景化占比 | 第4步 |

### 第6步 · 激励方案生成（各维度都有 · 缺口×杠杆配权重）
| 维度 | 激励形式（模板） | 计量口径 |
|---|---|---|
| 留存 | 连续动销阶梯奖（连2月/连3月累加） | **严口径**+剔马甲 |
| 激活 | 新激活首单返利（元/户，满N台） | **严口径**+剔马甲 |
| 升档 | 跳档奖（跨V3/跨V4，V4奖≫V3奖） | 累计成交额跨档 |
| 新签 | 新户开张奖 | 新签并激活 |
| 品类 | 专项上线奖（短板品类单台奖最高） | 产品流向·专项标 |
| 底盘 | base-load达成返点 | 待定口径 |
- 预算分配 ∝（缺口大小 × 单位杠杆）；总盘建议 = SO的 4-6%（转型月可到5-8%）。
- **业务员侧**：内部PK/提成挂钩同一套严口径指标（成本从代理商提成池出）。

## 三、关键口径（防作弊 / 防误判）

| 口径 | 定义 | 用途 |
|---|---|---|
| **严口径** | 设备「上线时间」与「扫码领红包时间」**双双在当月** | 当月增量指标（激活/动销/升档）的激励计量，防补扫旧货刷量 |
| **存量分档** | 累计成交额（全周期），V2≥0.1万/V3≥1万/V4≥3万 | 服务商当前在哪一档 |
| **剔马甲** | `vest_account.对应一级` 匹配，剔除自营直单 | 区分真实渠道 vs 项目 |
| SO基准 | 产品流向·最新分销价（台数/金额） | 总盘考核 |
| 双口径占比 | 品类台数占比 vs 金额占比 | 高客单价品类看金额 |

> ⚠️ 易错点：① `install_redpack.上线客户编码`(实际上线服务商) ≠ `product_flow.上线自客户编码`(上线来源，多为"其他")——服务商归属必须用前者；② 累计超节奏可能掩盖月度下滑，必看逐月；③ 同序列号在两表的"最新分销价"与"产品现有分销价"一致（已验证），金额差异来自口径覆盖面而非单价。

## 四、数据源清单

| 表/视图 | 用途 |
|---|---|
| `product_flow_v` | SO台数/金额、专项品类、上线时间 |
