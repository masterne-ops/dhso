# SKILL: weekly-report（经营周报 · 只写分析,不渲染）

给浙江全省 / 单地市经营周报**写分析文字**。数据已由后端 tool 算好放在 JSON 里;
**你只负责读数据 + 写分析,把分析写回 JSON 的「分析」键。渲染由后端做,你不用碰 docx/html。**

## 🚨 五条铁律

1. **数字禁止自己算**。所有数字(SO/环比/完成率/同比/台数)都已在 JSON 里算好,引用时直接 copy,不要自己重算或重新格式化百分比。
2. **数字必有出处**。分析里写的每个数字 / 地市 / 区县 / 代理商 / 业务员名,必须能在 JSON 里找到。
3. **`***` 已改写**。数据里若出现"外省代理商在本省出货"就是 `***`(外省代理商的货在浙江上线),直接用这个名字,别写成 `***`。
4. **完成率低 ≠ 差**。必须对照「当月时间进度」看:完成率 14% 但时间进度才 20%,要写"月初进度偏慢、需加速",不能直接判差。本周环比回落但 YTD 高增的,点出"短期波动 vs 全年增长"。
5. **下阶段计划按 scope 派活**。责任方写大华业务员时,只能从该地市/区县实际负责人里选(数据有 `salesperson_scope` 就按它,没有就只点地市/代理商、不点具体人)。

## 输入

- JSON 路径:`/sandbox/output/work/weekly.json`(后端已写好,含全部数据,**没有「分析」键 → 你来加**)
- JSON 不大,可直接 `Read` 整个文件;或用 `python3 -c` 读。**先判断这是全省还是地市报告**:
  - 有 `范围`=「浙江全省」键 → 全省周报
  - 有 `地市` 键(单个市名)→ 地市周报

## 你要写的「分析」键(键名必须**完全一致**,否则渲染时丢失)

每个值是**字符串数组**(一条一个元素)。某条以 `1.`/`2.` 开头时,渲染成有序列表。

### 全省周报 → `分析` = {
- `总览`：本周全省 SO + 环比上周一句;当月完成率 vs 当月时间进度(是否跟上节奏);YTD 累计同比(全年趋势)。3-4 条,先定性。
- `地市`：红榜(环比领涨 top3)/黑榜(环比下滑 top3)点名;`②地市对比.异动下滑` 里的地市重点点出。
- `下钻`：`③异动下钻.明细` 里每个异动地市,写它的问题代理商(点名、环比掉多少)+ 周跑动环比。
- `专项`：夜视王/无线/场景化 三专项本周台数 + 环比,哪个降了要点出。
- `下阶段计划`：针对低完成率地市、异动下滑地市,列 2-4 条行动(有序列表 `1./2.`),点到地市/代理商。
}

### 地市周报 → `分析` = {
- `总览`：该市本周 SO + 环比;全省位次;当月完成率 vs 时间进度;YTD 同比。
- `趋势`：近几周 SO 走势一句(`①周趋势`)。
- `区县`：区县本周动态(`②区县`),领涨/下滑区县点名。
- `代理商`：代理商本周签约/激活/跑动动向(`③代理商跑动`+`服务商按代理商`),点名;`***` 用改写名。
- `服务商`：本周签约/激活(达 V2)数 + 任务达成率(`服务商KPI`);完成率对照时间进度。
- `专项`：该市三专项台数 + 环比(`④专项`)。
- `下阶段计划`：针对该市薄弱区县/代理商,列 2-4 条行动(有序列表),按 scope 点责任方。
}

## 流程

```python
import json
P = '/sandbox/output/work/weekly.json'
with open(P, encoding='utf-8') as f:
    J = json.load(f)

# 1) 判断全省/地市,读关键数据(自己 print 出来看)
#    全省看 J['①周趋势'] J['②地市对比'] J['②YTD累计同比'] J['③异动下钻'] J['④专项'] ...
#    地市看 J['①周趋势'] J['②区县'] J['③代理商跑动'] J['服务商KPI'] J['激活V2'] J['④专项'] ...

# 2) 据数据写分析(每键字符串数组),遵守五条铁律 + 报告写作规范:
#    书面平实、"多少→增长/下降"、一事一段、结论用有序列表、数字只引用不编。
analysis = {
    '总览': ["本周全省 SO XXX 万,环比上周 +X%。", "当月完成率 X%,当月时间进度 Y%,...", "..."],
    # ... 其余键
}

# 3) 写回 JSON 的「分析」键
J['分析'] = analysis
with open(P, 'w', encoding='utf-8') as f:
    json.dump(J, f, ensure_ascii=False, default=str)
print("✅ 分析已写回")
# stdout 再输出一句本周核心结论摘要(全省环比 / 红黑榜 / 异动地市)。
```
