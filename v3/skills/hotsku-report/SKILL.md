# SKILL: hotsku-report (爆款型号穿透分析)

> ⭐ **先读 `/sandbox/skills/system-overview/SKILL.md`**(口径单一真相源)。

## 报告定位

输入**一段型号关键字**(如 `T8`、`HDW2449`、`P5FC`),自动:
1. 在 `产品_flow_v` 里按字段 LIKE 匹配出命中的 SKU 群
2. 围绕这些 SKU 做 9 章穿透分析,产出**一份 HTML**

跟「产品维度报告」的区别:

| 维度 | 产品维度报告 | 爆款穿透(本 skill) |
|---|---|---|
| 主轴 | 105 个子系列 | 用户感兴趣的 SKU 群 |
| 范围 | 全省/单城市大盘 | 窄而深的单产品深挖 |
| 输出 | 概览 + 全量(2 份) | 单 HTML(综合版) |

## 🚨 五条铁律

**1. 匹配字段顺序:`内部型号` → `外部型号`(自动 fallback,不含产品名称)**
- 先搜 `内部型号 LIKE %kw%`,命中即停
- 没命中再搜 `外部型号`(很多新品如 DH-T8-AOV、DH-T8-G 系列只挂外部型号)
- **产品名称**(噪音大,会匹到标签号里的字符)— 不参与自动 fallback,只在用户显式指定时启用

**2. 双口径分轨(沿用产品报告)。**

| 维度 | 用哪张表 |
|---|---|
| SKU 列表 / 走势 / 地市 / 区县 / 代理商 / 价格 | **`product_flow_v.最新分销价`(🌐 全量感知)** |
| 服务商 / 渠道健康度 / 客群画像 | **`install_redpack_v.产品现有分销价`(🎯 红包扫码)** |

**3. 同环比对称。**
- 评估期 = 用户选(period_start, period_end)
- 同期 = 评估期 - 12 月
- 环期 = 紧邻评估期前 N 月

**4. 服务商标识沿用产品报告**:🎭 马甲全表 EXCLUDE,🚫 已关闭保留并标记。

**5. 评估期默认 4 个月**,但如果命中的 SKU 最早上线在评估期内(<4个月),自动用全周期(SKU 首次上线 → 数据最末月)。

## 报告章节(单 HTML)

```
顶部
  元信息卡(关键字 / 命中 N 个 SKU / 评估期 / 同期 / 环期)

一、命中的 SKU 列表(单卡)
  - 表:内部型号 / 外部型号 / 产品名称 / 子系列 / 三级
        当期货值 / 台数 / 均价 / 同比 / 环比
  - 命中 > 1 个 SKU 时,加 1 行「合计」
  - 状态评级:🔥 爆款上扬 / 📈 稳健增长 / 🟡 持平 / 🟢 新品爬坡 / ⚠️ 衰退

二、月度走势(近 12 月)
  - 折线/柱状(SVG inline)
  - 双 Y 轴:左 = 货值万 + 台数,右 = 均价

三、价格分布
  - 同型号实际成交价跨度(min / p25 / median / p75 / max + 标准差)
  - 当期 vs 同期均价对比
  - 价格降幅诊断

四、11 地市 × 同环比
  - 表:地市 / 当期货值 / 同期货值 / 同比 / 环比

五、Top 30 区县(当期货值降序)
  - 表 + 同环比

六、代理商分销份额
  - Top 10 代理商 当期/同期 货值 + 份额 + 同比
  - 「无签约代理商」单列(直营/散卖识别)

七、服务商生态(红包扫码口径)
  - Top 30 服务商(当期货值降序)
  - 客户类型分布(V4 / V2 / V1 / 未签约)
  - 渠道健康度:同期 vs 当期 服务商集合差异(新增 / 流失)

八、跨地域流向
  - 异城率 / 异省率
  - 异城货流向 Top 5 路径(出货城市 → 上线城市)

九、行动建议(自动诊断)
  - 自动规则触发的 1-3 条提示:
    - 月销翻倍且价格跌 → 「降价拉动型爆款,警惕透支」
    - 同比 ≥ +30% 且无降价 → 「自然增长,建议加大铺货」
    - 11 地市集中度 > 50% → 「区域过度集中,加 X 地市拓展」
    - 服务商数 ≥ 30% 是新签约 → 「正在扩散」
    - 跨渠道采购 > 30% → 「价格穿透,代理商话语权弱」
```

### 自动状态评级

| 级别 | 触发(任一) |
|---|---|
| 🔥 **爆款上扬** | 月销同比 ≥ +50% 且最近 2 月环比 ≥ +30% |
| 📈 **稳健增长** | 同比 ≥ +10% 且无明显降价 |
| 🟡 **持平** | -10% ≤ 同比 ≤ +10% |
| 🟢 **新品爬坡** | SKU 首次上线 ≤ 6 月前,数据少时强制走此分类 |
| ⚠️ **衰退** | 同比 ≤ -20% |

## 输入参数

```python
params = {
    'keyword':       'T8',
    'period_start':  '2026-01',  # 可选,默认数据最末月-3
    'period_end':    '2026-04',
    'city':          None,        # None = 全省
    'match_field':   None,        # None = auto fallback, 或 '内部型号'/'外部型号'/'产品名称'
}
```

## 输出文件

```
爆款穿透_{关键字}_{时段}_{域}.html
```

例如:`爆款穿透_T8_2026-01_to_2026-04_全省.html`

## 数据流

```
SQLite DB (product_flow_v + install_redpack_v + vest_account + closed_provider)
   ↓ runner.py
data dict (~50-200 KB)
   ↓ html.py
单 HTML 文件 (~ 200-500 KB,含 JS 排序/筛选)
```

## 工作流

```bash
python3 hotsku_report_runner.py --kw T8 \
        --period-start 2026-01 --period-end 2026-04 [--city 杭州市]
# → 输出 报告 HTML
```

## 自检清单

### Runner

1. ✅ 匹配字段 auto fallback:内部 → 外部 → 产品名称
2. ✅ 命中 0 个 SKU 时,清晰报错并建议改关键字
3. ✅ 命中 > 50 个 SKU 时警告(可能关键字太宽)
4. ✅ SKU 列表用 `产品_flow_v` (全量感知)
5. ✅ 服务商章节用 `install_redpack_v` 且 EXCLUDE 马甲
6. ✅ 评估期内全无数据时,自动放宽到 SKU 首次上线之后所有月份

### HTML

1. ✅ 顶部元信息含关键字 / 匹配命中 / 时段 / 同环期
2. ✅ 走势图用 inline SVG(无外部依赖)
3. ✅ 自动诊断卡片显示在顶部 + 行动建议章末重复
4. ✅ 文件 < 1 MB
