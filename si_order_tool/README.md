# 代理商智能备货配单

生产平台页面：`pages/45·🧮 智能备货配单.py`

主要能力：

- 自动识别生产库正式任务当前做到的月份，默认规划下一备货周期；
- 可切换后续月份，动态计算每家客户目标月底累计任务与下单缺口；
- 官方达成直接取“累计业绩达成（计任务）”；
- SI型号数量仅统计“行业一级=纯分销”且“外部型号≠discount”的明细；
- 用过滤后的 SI 进货型号数量、SO 30/60/90 天和年内结构进行整数配单；
- 支持新增、删除、替换内部型号以及修改下单数量；
- 型号变化后按最新分销报价自动带价，无法匹配时使用流向价或 SI 加权价回退；
- 实时显示配单金额、缺口差异和匹配度，并可导出单客户 Excel。

生产业务库只读，页面修改只保存在当前浏览器会话。
